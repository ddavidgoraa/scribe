# Scribe — plan

Decisions agreed on 2026-11-05. This is the source of truth for scope; change it deliberately.

## Goal & distribution

- Markdown editor with math for macOS, in its own minimal style. (Initially modeled on iA Writer; independent since 2026-11-17.)
- Open source on GitHub, MIT license.
- macOS 14+, Apple Silicon only (`aarch64-apple-darwin`).
- No App Sandbox; `.dmg` via GitHub Releases. Notarization optional, later.
- Bundle ID `dev.dawidgora.scribe`. UI in English (String Catalog); Polish in v0.2.

## Architecture

| Layer | Responsibility |
|---|---|
| `core/mdcore` (Rust) | Markdown parser with source spans (comrak / pulldown-cmark) → ranges for styling; library index; full-text search; file watching (`notify`); later export |
| `core/mdcore-ffi` (Rust) | UniFFI bindings |
| `app/Packages/MdCore` | Local Swift package: XCFramework + generated Swift |
| `app/Scribe` (Swift) | SwiftUI shell (`NavigationSplitView`, `@Observable`), editor = NSTextView + TextKit 2 via `NSViewRepresentable` |

- Parsing is debounced and incremental (changed block only), not per keystroke over the whole doc.
- Build: `scripts/build-core.sh` → cargo (aarch64) → uniffi-bindgen → XCFramework. Project generated by XcodeGen from `app/project.yml`.
- CI: GitHub Actions on macOS — `cargo test` + `xcodebuild test` on every PR; `.dmg` release on `v*` tag.

## Editor

- **Live preview (Typora-style).** The `.md` text in the buffer *is* the file; rendering is decoration only. Never lossy.
- Marker reveal rules:
  - inline (`**b**`, `*i*`, `` `code` ``, links, `$x$`): when the caret touches the span
  - headings: `#` visible when the caret is on the line
  - blocks (`$$…$$`, code fences, quotes): whole source when caret is inside; `$$` also shows a live preview below
  - images `![](…)`: thumbnail when caret is outside
  - mouse selection across blocks does not reveal markers until typing
- Syntax: CommonMark + GFM (tables, task lists, strikethrough, autolinks) + footnotes + `$` / `$$` math.
  Tables are shown as styled monospace source (no grid editor in MVP).
- Math rendered natively with **SwiftMath** as `NSTextAttachment`. Parse errors → red source + hint.

## Library & files

- One root folder; folder tree in sidebar; only `.md` shown; sort by modified date or name.
- Autosave ~1 s after last keystroke and on file switch; atomic writes (temp + rename).
- External change (`notify`): no local edits → silent reload keeping caret; local edits → banner "Reload / Keep mine".
- ⌘N creates `Untitled.md` (`Untitled 2.md`, …). Auto-naming is stateless (works after restart): a note follows its first line
  while its name is `Untitled [N]` or equals the title of its first line (± ` N` suffix); a manual rename to anything else stops it. Toggle in settings.
- Pasted / dropped images saved to `assets/<note>-<timestamp>.png` next to the note, inserted as relative path.
- Rename in sidebar.

## Look

- System fonts only (nothing bundled): Sans = SF Pro (default), Serif = New York, Mono = SF Mono; code always SF Mono.
- Centered column ~64 chars, line height 1.5; headings bold and slightly larger.
- Light/dark following system; blue caret; minimal chrome; sidebar toggle ⌘⇧L.
- MVP settings: font + size.
- MVP: typewriter scrolling (⌘T) + paragraph focus (⌘D); sidebar ⌘⇧L; text size ⌘+ / ⌘− / ⌘0.

## UI "Paper" (v0.2 design, decided 2026-11-11)

Direction A from the UI proposal: the window is a sheet of paper; chrome appears on demand.
- Hidden title bar, no toolbar; the note name is shown dimmed at the top.
- Floating library panel (⌘⇧L), **hidden at launch**; the last open note reopens. Search field, Recent, tree without
  icons, dates on the right; Liquid Glass on macOS 26+ (`disableGlass` default turns it off), solid panel before.
- Status pills (words · reading time, saved state, modes) on pointer movement; conflict toast; calm empty states.
- Spotlight-like Quick Open; ⌘⏎ creates a note titled with the query.
- **Neutral white** palette (`Palette`), one accent (Scribe ink blue #2D5BE3 / #7C9BF5 dark); line length 64 / 72 / 80.

## Notes

- Highlighting: full parse on every edit (≈28 ms for 520 KB in release, sub-ms for typical notes), but only the
  paragraphs whose spans changed are restyled (`SpanDiff`). Revisit with incremental parsing if large notes lag.
- Live preview never changes the text: hidden markers get a 0.01 pt clear font; math/images are drawn by
  `DecoratedLayoutFragment` (TextKit 2) over hidden source, space reserved by `.kern` (inline) or line height
  (blocks). Math is rendered by SwiftMath as a black mask and tinted with the view's label color.
- Code blocks use a line-spanning background drawn by `DecoratedLayoutFragment` (`.scribeBlockBackground`).
- Focus mode dims every paragraph fragment outside the caret's block (lines between blank lines) by drawing it
  at 30% alpha; typewriter mode pads the text by half a screen and scrolls the caret line to the middle.
- Image paste/drop (`ImageInsertion`): image data → `assets/<note-slug>-<yyyyMMdd-HHmmss>.png`; files from outside the
  library are copied to `assets/`, files inside are linked relative to the note; inserted on their own line.
- App Sandbox (since the security pass): user-selected read-write + app-scope bookmarks for the library folder,
  plus network.client only because WebKit (Help window) requires it; the Help view blocks all web requests.
  Older versions stored the library as a path, so after the update the folder is chosen once more.
- Website: `site/` templates + `core/scribe-site` (renders docs with mdcore, GitHub-style heading ids, links
  rewritten to pages) → GitHub Pages via `.github/workflows/pages.yml`, which skips while the repo is private;
  `scripts/github-settings.sh` enables Pages once public. URL: https://ddavidgoraa.github.io/scribe/
- Printing (⌘P): `NotePrinter` lays the note out in a TextKit 2 `PrintableNoteView` styled by the highlighter in
  print mode (bullets, checkboxes and rules typeset; hidden syntax removed from the printed copy so PDFs carry no
  Markdown in their text layer), light colors, print font size, page breaks that never split a line, title and
  page number in the footer. The Help window prints its guide via WebKit.
- Release: `scripts/make-dmg.sh` (also used by CI on `v*` tags) builds an ad-hoc signed, non-notarized DMG.

- Release profile sets `strip = false`: stripping corrupted host proc-macro dylibs on the local toolchain
  (`dlopen: mis-aligned LINKEDIT string pool`). Revisit when the toolchain updates.
