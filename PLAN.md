# Scribe — plan

Decisions agreed on 2026-11-05. This is the source of truth for scope; change it deliberately.

## Goal & distribution

- Markdown editor with math for macOS, modeled on iA Writer.
- Open source on GitHub, MIT license.
- macOS 14+, Apple Silicon only (`aarch64-apple-darwin`).
- No App Sandbox; `.dmg` via GitHub Releases. Notarization optional, later.
- Bundle ID `dev.dawidgora.scribe`. UI in English (String Catalog); Polish in v0.2.

## Architecture

| Layer | Responsibility |
|---|---|
| `core/mdcore` (Rust) | Markdown parser with source spans (comrak / pulldown-cmark) → ranges for styling; library index; full-text search; file watching (`notify`); later export |
| `core/mdcore-ffi` (Rust) | UniFFI bindings |
| `app/Packages/MdCore` | Local Swift package: XCFramework + generated Swift |
| `app/Scribe` (Swift) | SwiftUI shell (`NavigationSplitView`, `@Observable`), editor = NSTextView + TextKit 2 via `NSViewRepresentable` |

- Parsing is debounced and incremental (changed block only), not per keystroke over the whole doc.
- Build: `scripts/build-core.sh` → cargo (aarch64) → uniffi-bindgen → XCFramework. Project generated by XcodeGen from `app/project.yml`.
- CI: GitHub Actions on macOS — `cargo test` + `xcodebuild test` on every PR; `.dmg` release on `v*` tag.

## Editor

- **Live preview (Typora-style).** The `.md` text in the buffer *is* the file; rendering is decoration only. Never lossy.
- Marker reveal rules:
  - inline (`**b**`, `*i*`, `` `code` ``, links, `$x$`): when the caret touches the span
  - headings: `#` visible when the caret is on the line
  - blocks (`$$…$$`, code fences, quotes): whole source when caret is inside; `$$` also shows a live preview below
  - images `![](…)`: thumbnail when caret is outside
  - mouse selection across blocks does not reveal markers until typing
- Syntax: CommonMark + GFM (tables, task lists, strikethrough, autolinks) + footnotes + `$` / `$$` math.
  Tables are shown as styled monospace source (no grid editor in MVP).
- Math rendered natively with **SwiftMath** as `NSTextAttachment`. Parse errors → red source + hint.

## Library & files

- One root folder; folder tree in sidebar; only `.md` shown; sort by modified date or name.
- Autosave ~1 s after last keystroke and on file switch; atomic writes (temp + rename).
- External change (`notify`): no local edits → silent reload keeping caret; local edits → banner "Reload / Keep mine".
- ⌘N creates `Untitled.md` (`Untitled 2.md`, …). Auto-naming is stateless (works after restart): a note follows its first line
  while its name is `Untitled [N]` or equals the title of its first line (± ` N` suffix); a manual rename to anything else stops it. Toggle in settings.
- Pasted / dropped images saved to `assets/<note>-<timestamp>.png` next to the note, inserted as relative path.
- Rename in sidebar.

## Look (iA)

- Bundled iA Writer Mono / Duo / Quattro (SIL OFL); default Duo.
- Centered column ~64 chars, line height 1.5; headings bold and slightly larger.
- Light/dark following system; blue caret; minimal chrome; sidebar toggle ⌘⇧L.
- MVP settings: font + size.
- MVP: typewriter scrolling + paragraph focus.

## Shortcuts

⌘B ⌘I ⌘K (link) ⌘1–6 (headings) ⌘⇧M (math) · ⌘P quick open · ⌘⇧F library search · ⌘F in-file find · ⌘N new file

## Tests

- Rust: `insta` snapshot tests (markdown → spans), index & search tests.
- Swift: unit tests of marker-reveal logic as a pure function (spans + caret → visible ranges).
- UI: one smoke test (open library, type, verify save).
